## Governance

Implementation must follow the approved Oath of Care phase-gate process.

Do not begin application implementation until the relevant upstream phases are approved.

Current restrictions include:

- no Java/Spring Boot scaffolding
- no database schema or migrations
- no authentication implementation
- no API implementation
- no frontend scaffolding
- no deployment configuration
- no copied legacy Python source or secrets

Phase 00 — Master Orchestrator remains the project control authority.
